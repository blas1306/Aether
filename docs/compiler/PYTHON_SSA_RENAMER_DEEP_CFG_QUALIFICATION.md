# Python SSA renamer deep-CFG qualification — SSA-ROBUST-1

Decision: `PYTHON_SSA_RENAMER_DEEP_CFG_QUALIFIED`

## Root cause and architecture

The minimized 993-block linear CFG has a 993-node, 993-level dominator-tree
chain (one dominator child per non-leaf block). The production call path was
`SSARenamer.rename -> _rename_block -> dominator child -> _rename_block`, so
Python call-stack depth grew linearly with dominator-tree depth. The failure was
not in CFG reachability, dominator analysis, dominance-frontier analysis, phi
placement, or phi incoming population; those paths are iterative. Any valid CFG
whose dominator tree contains a sufficiently deep chain could reproduce it,
including linear, nested structured, loop-chain, and exceptional-continuation
families.

The recursive DFS has been replaced by one explicit LIFO worklist. An ENTER
frame performs phi binding, slot pushes, instruction conversion, and successor
phi incoming population. It then schedules an EXIT frame followed by dominator
children in reverse deterministic order, which preserves the old sorted DFS
order. Each EXIT frame owns that block's exact `pushed_slots` and
`bound_values`; it reverses slot pushes and restores or removes prior value
bindings only after all descendants have completed. This preserves sibling
isolation and the former recursive return semantics.

An AST-based regression gate confirms the production traversal does not call
itself. The old recursive implementation exists only as a test oracle, not as a
second production path.

## Results

- Focused renamer/builder suites: **44 passed**.
- Exact iterative-vs-recursive object equality: linear 100-block and
  phi/naming-collision diamond fixtures passed.
- Production lowering and verification: **100, 993, 1000, and 5000 blocks**
  passed. Recorded wall times were approximately 0.012 s, 0.302 s, 0.269 s,
  and 6.866 s respectively.
- Fresh RUST-3.2 adversarial attempt: **21/21** positive cases completed and
  **7/7** negative cases were deterministically rejected. Lifecycle parity,
  canonical SSA parity, Rust verification, schema-v2 import/exact
  reserialization, determinism, and input immutability all passed.
- Fresh historical differential: **116/116** passed.
- Safe-size traversal micro-observation (100 blocks, 20 repetitions): iterative
  mean 3.136 ms versus recursive-reference mean 2.257 ms. The explicit frames
  add modest constant overhead but show no pathological regression; deep cases
  no longer fail at Python's recursion limit.

Machine-readable evidence is in
`python_ssa_renamer_deep_cfg_qualification.json`, generated by
`scripts/qualify_python_ssa_renamer_deep_cfg.py`. The historical
`RUST_SSA_LOWERING_ADVERSARIAL_BLOCKED` report and JSON were not overwritten.

No `sys.setrecursionlimit` call, retry-on-`RecursionError`, Rust lowering
change, schema/policy change, dominance/CFG/phi semantic change, production
authority change, or commit was made. Python remains the production lowering
authority and RP3 remains unchanged.
